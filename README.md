# Ly Thanh Loi — Fantasy × Tech Portfolio

Personal portfolio site for **Ly Thanh Loi** (HUTECH — Vietnam–Japan Institute). Dark fantasy × tech aesthetic with scroll reveals, project archive, and verified GitHub links.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

Production build uses **Turbopack** (`next build --turbopack`). On some Windows drives (e.g. exFAT), `npm run build` may fail with `EISDIR` during `readlink`. Development (`npm run dev`) still works on `D:\download`. For a local production build on Windows, run:

```powershell
.\scripts\build-ntfs.ps1
```

Deploying via **Vercel** or **GitHub Actions** (Linux) is unaffected.
